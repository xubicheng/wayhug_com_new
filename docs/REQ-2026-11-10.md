## 二、整站配色重做

基调四种色：**灰、淡橘、淡紫、单靛**。理解为：灰做骨架与文字层级，淡橘做暖意与提示，淡紫做次级强调与分区，靛蓝是唯一的重色（链接、按钮、重点）。
要求：
- 落成 CSS 变量（如 `--ink / --muted / --paper / --apricot / --lilac / --indigo`），**不要散落硬编码色值**；
- 正文对比度 ≥ 4.5:1、大字与按钮 ≥ 3:1，改完自己实测（之前的 `#a8794a` 就是栽在这上面）；
- 靛色只做"一次强调"，页面上不要出现两处抢眼的靛色按钮；
- 阅读区白底偏暖（米白），不要纯白刺眼；夜间不做自动切换，先只做浅色一种，别扩散范围。

## 三、读书笔记提交

**决定：站内表单入库，不走 QQ 邮件。** 邮件仅作「有新提交」的通知，做成 `.env` 开关，默认关。理由要写进方案文档：邮件会把九字段拍平成文本、ISBN 无法校验、日期无法排序、附件与链接易丢失、且增加人工搬运成本。

表单九项，**只有第 5 项（标题）必填**，其余全部可选：
1. 日期时间 + 星期几（选日期后星期自动算出并显示，可改；默认当前时间）
2. 地点（自由文本，允许留空）
3. 天气（建议做成轻量选择：晴/多云/阴/雨/雪 + 可选温度，而不是纯输入框）
4. 书名 + ISBN（ISBN 选填，但一旦填写必须校验 ISBN-10/13 校验位，错误时明确提示而不是静默忽略）
5. **读书笔记标题（唯一必填）**
6. 正文（多行，支持最简 markdown：段落、加粗、引用、链接；不允许裸 HTML）
7. 一个读书的思考 / 问题（单段，短）
8. 可选颜色 / 可选小旗帜（提供有限色板与几种旗标，用于个人标记，不能替代正文）
9. 相关超链接（可多行，逐条校验协议只允许 http/https）

提交体验：移动端优先，单列，键盘弹出不遮挡当前输入框；草稿自动存本地（`localStorage`），误关页面能恢复；提交后给明确回执编号（如 `WH-20261110-003`），并告知"审核后出现在读者笔记栏"。
反滥用：同 IP 频控、隐藏 honeypot 字段、长度上限、可选极简算术题；**不做强制注册**。

## 四、管理员审阅后台（这块要当作产品来做，不是 CRUD）

1. **待审收件箱**：默认进来就是「待审」队列，未读数显示在导航；列表每行给出标题、提交时间、书名、来源 IP 归属地（粗略）、字数。
2. **一屏内决策**：右侧或下方面板直接展开全文，不需要跳页；`A` 采纳、`R` 退回（带原因下拉：内容不完整/与读书无关/疑似广告/其他）、`J/K` 上下条、`⌘/Ctrl+Enter` 采纳并下一条。
3. **一键采纳**：采纳时自动生成正式笔记草稿（填好九项、生成 slug、按语言建 i18n 行），你只需补译文与配图再发布；采纳过程保留原始提交记录与快照，便于追溯。
4. **可编辑**：采纳前允许就地改标题、正文、标点，改动写入审计日志（谁、何时、改了什么字段）。
5. **筛选与搜索**：按状态、日期区间、书名、关键词；支持批量退回。
6. **空状态与错误**：队列空时给出"今天没有待审"，而不是空白页；提交失败要保留用户已填内容。
7. 后台里能看到提交表单的**实时预览**（同前端渲染一致），避免采纳后才发现排版崩掉。
